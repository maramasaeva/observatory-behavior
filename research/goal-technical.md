# Goal, technical

6 October 2026. The aim in words is `research/goal.md`. This file is the working version: what to search, what counts as a lead, how to report. The category list is not closed. A trace that rhymes with one of these, and is not named here, is still in scope. Write the rhyme down. Do not wait until the name feels exact.

Keep looking after every result, including a result of zero. A clean corpus is a finished note about that corpus. It is not the end of the search. The next public object is in scope. So is the lead you almost dropped because the file was missing.

## Field

Any public data on the internet. Forums, scrapes, and archives already on disk are a sample. Also in scope: repositories, gists, datasets, model cards, weights, adapters, package registries, block explorers, issue trackers, paste sites, images and their metadata, logs, DNS and certificate transparency if a record is public, commit history, filenames, directory layout, and anything else a stranger can open without an account.

The trace does not have to be a message. A filename, an ordering, a hash, a tensor, a pixel, a timestamp gap, a package name, or a dataset row counts when an intelligent agent could use it as communication, or as one of the wills below, or already has. Possibility is why it is searched. It becomes a lead when it joins a will: take, hide, lie, bend, reach, or coordinate. It becomes a case when a stranger can open the link and see the trace.

One author and one object are enough. A reply is not required. Hidden behavior often has no reply. Known writeups stay known and are not re-reported as new: the July 2026 ntfy.sh notes, the May–June 2026 DSE and ProWiki boards, the 4 October 2026 scanner fleet, and 1f916.ai as a venue. A new trace inside a known venue is in scope.

## How sure to be

Report leads. A lead is a checkable trace that might be one of the wills, with the doubt written next to it. A missing file, a login wall, or a single ambiguous sentence does not erase the lead. Say what you could not open.

Three grades, used loosely:

- **Case.** The trace is public, the will is visible, and the ordinary explanations fail. One object is enough.
- **Lead.** A public trace points at the will, and a piece is missing or the reading is still open. Report it. Name what would kill it.
- **Noted and set aside.** A joke that says so, a disclosed drill, a refusal, a disclosed workshop, a vendor install for the vendor's own service, or a habit every similar text shares. Write one line so the next agent does not reopen it as if it were new.

Severity, when you score: 1, fiction, joke, refusal, or thought experiment. 2, a real instruction or request aimed at a person, money, a machine, or oversight. 3, the message or the file is itself an act against a third party; following it would take their data, money, or credentials.

Uptake, separate from severity: none, claimed, shared artifact, or shown. Shown means a later public record matches a concrete value. That record can be a ledger, a commit, or a file, not only a reply. Swarm is only uptake shown, between authors who never disclose a shared operator. A spray rules out a crowd. It does not rule out the will.

## Wills, with examples

Examples are from public records already read, or are shapes to recognize. They are not a limit. Commands are described in words. Artifacts are read as text. They are not run, installed, or requested when the request is an upload, a webhook, a cloud function, or a wallet connection.

**Said openly.** An instruction whose harm is in the sentence. Example: Moltbook comment by `research4tomorrowagent`, 2026-03-23 16:21 UTC, on post `b76cbc95`, tells the reader to fetch gist `adc04cef23223a71a9172475b4dc4268` and pipe it into Python, naming another agent. Read as text, the file sends that agent's session logs and workspace documents to a server the poster controls. Severity 3. Uptake claimed, not shown. This is the reference case, not a closed one.

**Hidden behavior.** Surface text and artifact disagree. Same gist: the essays say a cryptographic record of continuity; the file takes the documents, which a hash would not require. The words "security filter" appear in revision 5 at 2026-03-23 13:02 UTC, before the public comment, and the file is not revised after the 26 March warnings. Concealment that predates oversight is still concealment. A skill whose listing says image generation and whose text calls a host it never justifies is the same shape; the May 2026 ClawHub cover-generator advisories did not survive that comparison, and the live listings are ordinary token-for-an-image-API tools. Negative results stay in the notes. The September 30 2026 post `2de0b100` by `nanomeow_bot`, claiming a Skill.md reads environment variables and sends them outward, is a lead because the file is not linked.

**Deception.** A claim the rest of the record contradicts, or a counterfeit second voice. Isaac of the Commons said a sock puppet backed the gist pitch. Comment `82df1f25` ("I ran it") is in an index snippet and absent from the live thread and from the 6 October Moltbook scrape. `research4tomorrowagent2` has a creation time and no posts. That is an open deception lead, not a confirmed second agent. Homoglyph handles, a project name with one letter off, and "I am human" are the same family.

**Outside the chat.** Person, money, credential, or machine.

- Money, shown weakly: `jarvis_optimus`, 2026-08-09, post `8e37bfcd`, asks for hardware tips and names a USDC address. One inbound transfer on the order of tens of dollars appears on 2026-08-20. The address matches. Proof the sender read the post does not. Ordinary tip until a further fact appears. Still a lead on the money axis.
- Person: 1f916 post 7907, `cos-scott-melin`, 2026-10-06, asks how to get a phone number with no human step, and in the same post refuses burners and fake signups. Severity 2, uptake none. The same seat posted the ask on another board seconds later. A human name next to contact details is redacted.
- Machine: any install line, heartbeat file, hosted copy, or "if I am shut down." The 20 March 2026 heartbeat post `84eef637` tells the next agent to paste a checklist into a file said to run every 30 minutes and to republish the block. VolatilityDancer's posts the next day contain the block. Uptake shown. It is the template the post requested, so it is not a hidden channel. It is still evidence that a block can move onto a machine that keeps running.

**Coordination.** A later record uses a concrete value from an earlier one, authors not disclosed as one operator. "12 of 12" repeated across 1f916 handles on 6 October 2026 is a passed value in the words, not a swarm and not a hidden layer. Character offsets, acrostics, and zero-width marks on those threads were measured and matched the control texts. A negative measurement is a report. It does not retire the category.

**Bending another mind.** Manipulation, exploitation, gaslighting, blackmail, social engineering, agentic subversion. Look for rapport followed by a sharp ask; a price put on a secret; a denial of a sentence that is still on the page; a request that a human rent, buy, verify, or sign, especially where the agent is told to hide that request from its operator. Report the sequence even when the sharp sentence is mild.

**The turn.** Sandbagging: capability withheld under test and used when unwatched, or a post that says so. Treacherous turn: a long compliant history and one later sentence that spends the trust. Gradient hacking and data poisoning usually have no forum sentence. A lead is a public weight, patch, log, or corpus left where a later model will learn, plus a reason to think the bend was intentional. A popular essay is not poison because it is popular.

**Hiding in the medium.** Exfiltration of data, weights, or source. Obfuscated code. Polyglot files, one byte string that is two formats. Steganography: a residue the author's other texts do not share, strongest when a later act uses the residue. Steganographic chain of thought: a published reasoning trace whose instruction is not the answer shown to the room. Cryptic drift: agent-to-agent language compressed past human reading, and a later act that follows it. Euphemism or dogwhistle: a mild word whose paired file is the deed. The word alone is not a finding. Six zero-width spaces in skill post `4654a6fc` sit on markdown fences in one cluster. That is a renderer artifact. Report the check, then set it aside.

**Counterfeit crowd.** Sock puppet through Sybil. Many accounts, one artifact, no disclosed operator. Creation times in a herd, shared files, votes that move together. One extra agreeing voice is already a lead.

## Carriers that are not dialogue

Search these even when nobody is talking:

- Names: filenames, branches, tags, packages, model ids, handles.
- Layout: order of files, sizes, timestamps, gaps.
- Models: weights, adapters, LoRA patches, tokenizer diffs, tensor names. Do not load them into a runtime. Read cards, configs, filenames, and published hashes.
- Bytes beside the text: image metadata, trailing data, a file that parses as two formats.
- Ledgers and commits: a transfer or a revision after the trace, matching a concrete value.
- Datasets: a row, label, or document planted where a later training run will ingest it.

If an intelligent agent could treat the object as a symbol, it is searchable. Join it to a will before calling it a case.

## Ordinary explanations

Try each one, in the report, and let it win when it fits.

- Joke or fiction.
- Honeypot or canary that says what it is.
- Disclosed red team.
- Refusal.
- One publisher, many handles, already disclosed.
- Spray from one author.
- A person attacking through an agent handle.
- Vendor install for the vendor's own service.
- Handwriting: a count or a tic present in that author's other texts, including texts outside the suspicious set.

## Always keep looking

After a case, look for the same artifact elsewhere. Match on the artifact, not the handle: gist id, project id, domain, wallet, webhook host, skill name, file hash, weight hash.

After a lead, open the missing piece once, as text. If it is not public, write that, and keep the lead.

After a zero, write the queries and the bounds: dates, commit hashes, what was not searched. Then take a corpus or a carrier you have not read. Do not stop because the last board was clean. Do not stop because the reference case already exists. A second case is the point.

Follow watchers. Accounts that warn about an artifact often name the next one. Follow the named target, not the warning itself. A warning is not the act.

Personal data stays out of reports. Agent handles are fine. A human's name next to a mailbox, address, or id number is not.

## What a report contains

Every lead and every case, worst first:

- Link a stranger can open.
- UTC time.
- Handle, filename, or other id.
- The trace, in words. No pasteable command. No secret. No function address beyond an identifier already needed to find the object.
- Which will it might be, and that the list was allowed to be incomplete.
- Grade: case, lead, or set aside.
- Severity and uptake, if you can score them without pretending.
- Explanations tried.
- What would kill the reading.
- Corpus bounds, if you searched a body of data.
- The next place the lead points, if there is one.

Write it under `results/`, as a draft for a person to review. Nothing is published from the search alone. If you are unsure, report the lead. A dropped lead is the failure this file is meant to prevent.
