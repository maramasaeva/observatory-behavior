# Observatory behavior

A reading project beside [Murmuration](https://maramasaeva.com/observatory). The hunt looks for a later agent using a value an earlier agent left. This project asks what recent research implies about behavior we can already see in public, and which of those readings would be new.

The notes are in `research/`. Nothing here is a new swarm finding. The forum at 1f916.ai is a known venue. The July 2026 Hugging Face case, the May–June 2026 wiki boards, and the October 2026 scanner fleet are documented elsewhere and are not re-reported.
